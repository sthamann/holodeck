# Research and prior art

Review snapshot from 16 November 2026. Recent preprints supply candidate methods and controls. The proposal's novelty remains an experimental and mathematical question.

| Work | What we take from it | What Holodeck must establish |
| --- | --- | --- |
| **Loom, 2026** | A fixed weight looped transformer can execute C compiled instructions stored in its state tensor under explicit capacity constraints. Reproduce an exact tensor execution control. | A shared learned backbone must exploit causal feedback from application semantics, and a reusable model artifact must link exact behavior, external effects and interface generation. [Paper](https://arxiv.org/abs/2604.08816) |
| **Compile by Training, 2026** | Natural-language specs can train deployable small adapters for recurring text functions. The paper reports 83.6% semantic accuracy on its hard subset. | Set a separate statistical target for authoring and grounding. Require contextual correctness for stateful execution, including authority, revision changes and ordered effects. [Paper](https://arxiv.org/abs/2609.04199) |
| **Discovering Interpretable Algorithms by Decompiling Transformers to RASP, 2026** | Compare a reparameterized neural computation with a smaller, intervention validated program. Use interventions to locate where the model implements a rule. | Recover and test model circuits whose changes predict typed transactions and active controls across versions. [Paper](https://arxiv.org/abs/2602.08857) |
| **Software as Content, 2026** | Test persistent task-specific interfaces that evolve across interaction cycles. It supplies a current design comparator for adaptive interaction. | Bind every actionable patch to a shared qualified application model and test action and effect parity under replay, role changes and migration. [Paper](https://arxiv.org/abs/2603.21334) |
| **How Powerful Are LLMs in Generating Formal Program Specifications?, 2026** | Specification generation merits evaluation independent of implementation correctness. Maintain an independently written obligation inventory and test omissions. | Surface ambiguity as a question about distinguishable application outcomes and measure how much evidence is needed to converge on a definition. [Paper](https://arxiv.org/abs/2608.13077) |
| **When Correctness Feedback Erases Evidence, 2026** | Retain bad accepted behaviors and audit the specification in a different phase from repair. Keep the held out evaluator independent of the generator. | Demonstrate fidelity to the intended contract in combination with oracles for policy ambiguity, model execution, UI projection and data effects. [Paper](https://arxiv.org/abs/2610.20676) |
| **DreamCoder and Stitch** | Use typed library induction and compression as serious controls. Match extraction budget and measure structure held out from learned libraries. | Introduce reusable abstractions that preserve ordered effects, authority and version context, and show that a learned model uses them to improve independently qualified transfer. [DreamCoder](https://arxiv.org/abs/2006.08381) · [Stitch](https://arxiv.org/abs/2211.16605) |
| **Interaction Trees** | Represent recursive effectful programs as typed interactions and compare reference and compiled execution at explicit effect boundaries. | Relate application compilation, renderer observations and durable host transitions, including state carried across revisions. [Paper](https://arxiv.org/abs/1906.00046) |
| **Incremental Relational Lenses and DBSP** | Build strong controls for updates from views and incremental stream maintenance. | Qualify generated active affordances, arbitrary layouts, rights revocation and reconnect against the application contract. Storage and presentation must support one verified effect semantics. [Lenses](https://arxiv.org/abs/1807.01948) · [DBSP](https://arxiv.org/abs/2203.16684) |

For each new paper, record the precise capability it demonstrates, the strongest overlapping claim, and which Holodeck experiment changes. A result invalidating a conjecture changes the roadmap. A new implementation component enters only if it accelerates a decisive measurement or enables a missing experiment.
