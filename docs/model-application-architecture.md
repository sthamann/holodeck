# From application definition to executable model

## The compilation boundary

An application definition consists of typed values and stable identities, input and output signatures, invariants, externally visible obligations, authority, and contracts for time, external effects and failure. It can arrive as prose, examples, schemas, formal rules or observations from prior software. The authoring model builds a typed specification and asks a distinguishing question when two admitted policies disagree on an observable history. If the remaining choice can be explicitly delegated, the compiler records the choice and its scope. The compiler may return a counterexample, an unresolved obligation or an executable Deck with an independently checked certificate.

A Deck contains a model reference, typed executable modules, learned module parameters, effect and resource contracts, the scope of proofs, revision identity and translation evidence. Each qualified module has exact execution semantics. A generic Host transports typed events, supplies pinned live data, constrains effects, commits valid proposals and maintains receipts. Physical state can be relational, a log, a document store or a combination joined through explicit contracts. The runtime can fall back to a reference evaluator during development and qualification. The model-owned deployment experiment must attribute the decision path to the deployed checkpoint.

## Mathematical object

Let an event carry an actor, an authorized input or external stimulus, and a declared scheduling or clock choice. A legal history is a sequence of these events and outcomes from an allowed initial configuration. The abstract state includes live logical facts, policy revision, authority, pending continuations and their pinned contracts, and sufficient receipt state. Outcomes include refusal, authorized observations, ordered effect intents at the declared boundary, committed receipts and the semantic keys of actionable controls. View layout and model prose can vary within a declared observational tolerance.

For a fixed contract and scheduler model, two reachable histories are equivalent when their current allowed observations agree and every admissible future context yields the same observations and receipts, recursively. Input offers include attempts that can be refused. The context language includes view changes, identity substitution with capture avoidance, role changes, retries, restart, compatible storage migration, and admitted version activation. External results enter as typed stimuli. The first proof uses deterministic labeled transitions with explicit environment choices. Fair and concurrent histories later require a stated weak/strong simulation or testing equivalence and explicit schedulers. Equality of trace sets alone does not justify substitution for arbitrary interactive nondeterminism.

Write obs for the declared observation and q for the history quotient. For a finite, input total deterministic reference, the largest observation preserving right congruence exists. Its reachable quotient is minimal among deterministic realizations over that signature, unique up to isomorphism. Partition refinement computes it. This is the starting theorem from automata semantics. It must be generalized through proofs or explicit counterexamples to the following obligations.

### Retention under an evolving contract

Fix a common set of reachable source histories. Let q0 use the current context language and qM include a declared family of compatible upgrades and migrations with their observable obligations. Every current context is available to qM. Thus qM refines q0, with a projection from qM classes onto q0 classes. The coarsest valid retention can change when the set of admissible future policies changes.

**Finite retention lemma.** If the encoding retains q0 and at most b extra fixed bits per source history, then b is at least the ceiling of the base-two logarithm of the largest fiber of that projection. Two qM classes in the same fiber share q0. If the encoding gives them the same extra bits, a legal continuation that distinguishes the classes cannot be computed from the encoding. Conversely, enumerate the classes within each finite fiber and retain the index. This recovers qM with the same bound. The argument requires that all future-distinguishable information be recoverable from the encoding and the common external inputs; it permits redundant representations.

The lemma establishes an information bound. Correct adapters also need to preserve transitions, atomicity and receipts. Exact compiled models may keep redundant state, while a minimal deterministic realization is isomorphic to the quotient. Strict refinement requires a witness. The runnable finite fixture supplies one. The research problem is to derive compact, compositional fiber bounds from typed upgrade and dependency contracts without enumerating histories or global states.

### Research conjecture A · Modular context completeness

Given two typed Deck fragments with an explicit shared effect boundary, find an interface summary that preserves contextual distinctions when either is compiled and replaced by its quotient. With local steps, test whether witnesses factor over *reachable dependency structure* rather than the Cartesian product of local states. Permission changes, pending effects and order create cases in which each local observation agrees and the composition differs. Candidate sufficient conditions include closure of each fragment under all partner inputs, frame conditions on private state, and an explicit ownership and ordering discipline for shared effects. Establish a completeness theorem with a boundary size or treewidth bound, or show why those conditions are insufficient. Quantify witness, proof and execution costs separately. With no proved locality, use full reachable products on bounded cases.

### Research conjecture B · Transport across storage and projections

For an adapter B, let decodeB map qualified durable state to abstract state. Each completed physical action must refine exactly one abstract step or declared stutter, with the same receipt and observable effect order. Preserve initial relatedness, isolation, failure recovery, migration, and continuation identity. Obtain trace equivalence only when both directions of simulation or an equivalent completeness argument hold. Duplicate externally visible effects violate the relation. A connector with at least once delivery can qualify only against a compatible effect contract, such as one with an external idempotency key.

A generated Holo consists of a scene projection and an action interpretation. A patch sequence is valid when applying it yields the current intended scene up to allowed layout variation, and every actionable handle names an authorized semantic action at its scene and policy revisions. The server rechecks current rights and concurrency at invocation. A stale interaction returns an explicit conflict or a semantics preserving rebase. Presentation equivalence is evaluated over authorized actions and their future observations. Streams therefore have semantic as well as visual correctness. Under the adapter and projection laws, compare the abstract traces of a composed execution across Holo, API and agent. Prove the joint law under precise conditions and construct short witnesses when any condition is omitted.

### Research conjecture C · Learned semantic compression

Induce parameterized modules over typed identities, temporal state, capabilities and effects. Minimize a predeclared cost over module description length, residual obligations, evidence needed to select a hypothesis, and execution cost, subject to all certified obligations. Freeze coding conventions before measuring compression. A shorter representation earns research credit only if its licensed instantiations preserve behavior and it improves independently held out transfer at equal correctness. Alpha renaming, policy changes and new coupling topologies probe three different claims.

### Expressivity and identifiability

For a formal definition supplied as executable operational semantics, an idealized unbounded core with iteration, addressable data and typed I/O should simulate a universal register machine. Specify and prove the reduction. A deployed model has explicit finite memory, arithmetic, time and effect bounds and can return resource exhaustion. Neither universal computation nor statistical prediction decides arbitrary equivalence or termination. In the evidence-only track, two contracts may give every permitted probe the same answer while diverging elsewhere. Return the unresolved distinction, assumptions or scope. Certificates establish entailment from a declared contract. Validation of that contract against human intent is a separate obligation.

### Independent review and design choices

A Fable 5.2 review identified two risks: exact compilation could amount to a tensor VM, and gradient training alone could make correctness uncheckable. The constructive path is the primary build. The recurrent path is a research comparison for discovering modules and abstractions. Qualify extracted semantics against the same declared contract. Give the external control exact lookahead and the enabled action set. A tie at matched budgets narrows the model integration claim. The initial retention lemma, including its assumptions about redundant state and transitions, is weaker and more precise than stating that injective storage alone proves behavioral equivalence.

## A decision semantics for exact effects and uncertain goals

Separate authorization, the possible outcomes of authorized plans, and the user objective. An affordance set is sufficient for admission. It is insufficient for choosing a plan when a policy revision changes its exact effects without changing which actions are legal. The new reference contains two such rank reversals and drives a typed Holo from the selected plan's actual outcomes.

For a finite set of plans, let a plan's score be `w × time + (1 − w) × price`, with the units fixed by the objective contract. Legal plans with the same score may tie. The minimum-score plans form a piecewise constant set-valued function on `[0, 1]`. Each pairwise difference is affine, so it changes sign only at its exact rational crossing. Retain each crossing that changes the minimizer set, including point ties. This yields a canonical decision representation for the declared objectives. Two effect tables with the same representation permit the same optimal choices for every weight. Raw time and price remain available for truthful projection and receipt verification.

If a user objective admits any weight in `[lo, hi]`, a plan is valid for the whole interval exactly when it minimizes the score at both endpoints. In each pairwise comparison the candidate's advantage is affine, so its minimum over the interval is at an endpoint. If the two endpoint minimizer sets have empty intersection, a policy that guarantees optimality for every admitted objective must obtain more intent before committing. A plan can carry a certificate bound to the effect table, objective interval and plan identity. The current implementation recomputes the exact effect table at the Holo handle's epoch, checks the two inequalities against every competitor, and commits the whole plan through a compare-and-swap. A certificate cannot validate the language model's interpretation of a person. Grounding accuracy and false automatic commits are measured independently.

## Discovering objectives without a fixed effect vocabulary

The [objective discovery pilot](../experiments/model-applications/elicitation/README.md) compiles hypotheses from typed, ordered application effects and keeps all hypotheses consistent with the accessible comparison transcript. A state admits a certified choice when the target optima intersect. No reachable clarification can certify a choice if every feasible complete response signature contains objectives with empty common optima. This gives a second exact terminal condition for the query planner. Both proofs are relative to the declared hypothesis grammar and query interface. Reusing a certified decision on a changed target requires recomputing the intersection from the original evidence and the new effect table.

A separate rational solver extends the same decision condition to a continuum of linear utilities. It first proves that the strict comparisons have a common feasible weight, then checks competitor differences on the closed feasible polytope. A counterexample can be perturbed toward the strict witness without losing its negative margin. The proofs certify behavior across every remaining compatible intent in those models. They do not imply that the grammar represents every possible intent.

## Shared weights across formal applications and scoped symmetry

The [structural compiler](../experiments/model-applications/structural/README.md) lowers a bounded fragment of published PDDL definitions to role-indexed affine and threshold modules. An action binds concrete data slots to a shared weight graph. Independent truth-table checks verify its executable obligations against the formal source, grounded transition kernel and flat compiler. The module library is unchanged when object multiplicity changes within its certified role patterns.

The same constraints also determine which states and actions may be collapsed for planning. Generated permutations must preserve the transition relation and the current observation, including path invariants. A user can distinguish previously exchangeable objects by changing that observation. The next plan refines the quotient from the concrete current state, while executable weights continue to implement the same operations. A certified plan carries ordered concrete identities, observes path constraints at every step, and binds its effects to the current epoch for one atomic write. Symmetry is a planning optimization relative to an observer. The durable state retains identities needed to refine future observations.

## Changing a request while a Deck is running

Ground a request against the current Deck vocabulary. A meaning is an end condition with optional path invariants. Keep all meanings admitted by the grounding model. In the unit-cost fragment, compute each meaning's optimal path length and the optimal path length of their conjunction. Joint feasibility implies individual feasibility. The joint optimum is therefore at least each individual optimum. When all lengths are finite and equal, any shortest joint path is optimal for every retained meaning.

The [scope replay](../experiments/model-applications/intent/README.md) implements this rule with a declared lexicon. Its proof binds the request, candidate meanings, Deck checkpoint, epoch and ordered effects. The Host verifies the joint path again when it commits. If costs differ, the pilot names a constraint whose scope needs clarification. This is a semantic filter for a future learned grounder. Independent tests must measure whether the grounder retained the intended meaning.

## Streaming and data path

The model generates a structured scene for the current goal, authority and state revision. Each frame is a typed patch against a base revision with stable element identities, data dependencies, capabilities and accessibility semantics. The renderer handles layout, input, focus and device presentation. The Host reconciles missing or reordered patches by replay or snapshot and never treats a render event as a committed effect. Inspect bands from first usable patch to settled control states. Compare direct structured patch generation with a generic form and generated UI code using the same actions.

Normalize storage through logical identities, versioned transactions, event intents and deliveries. Define admissible consistency profiles and prove each adapter refines the appropriate profile. A migration is a checked transformation of live facts, receipt keys, open work and effect delivery commitments. Exercise recovery before and after each durable boundary. Choose physical storage and projection caching by workload and guarantees; application rules live in the Deck.
