# Compile formal application definitions into shared weight programs

This experiment translates independently authored International Planning Competition definitions into exact executable Holodeck artifacts. A single parser and compiler handle seven original tasks from the Gripper, Blocks, and Miconic domains. The input bytes are verified against pinned upstream Git blob IDs. The repository stores the source manifest, implementation and evidence. The published definitions are retrieved from the Fast Downward benchmark collection.

The parsed fragment is bounded conjunctive PDDL: static and dynamic predicates, positive and negative literals, object types and equality, and simultaneous add and delete effects. A grounded positive effect wins if the same action instance also deletes that atom. Unsupported sections, requirements and operators fail closed. The search has a declared state budget. Goals and operating invariants here are typed formulas. Durative actions, numeric fluents, uncertainty, open-world effects and free-form intent are outside this pilot.

## Three levels of exact reuse

1. **Executable weights.** Grounded guards and writes are described by the roles of their local slots. Each role pattern is compiled to an affine and threshold graph, then bound to concrete facts and symbolic action identities. An unchanged graph can execute in a different grounded object universe. Its label, data ports and action identifier remain explicit. Every local input valuation is checked against a set-based source interpreter, the bit transition kernel and the original flat weight compiler.
2. **State orbits.** Every proposed interchangeable-object block is generated by verified transpositions. Each transposition preserves the grounded transition relation, including names carried through corresponding actions, and preserves the current goal and path constraints. The exact fast path applies when each fluent touches at most one flexible object. Each block then becomes a sorted collection of object-local signatures. Under the proven group, two such signatures determine exact orbit equality. Harder relational couplings conservatively retain distinct objects.
3. **Action orbits.** In a concrete state, objects with equal signatures can still be permuted without changing that state. Grouping enabled actions by this stabilizer removes duplicate successor expansion. The grouping preserves argument equality and concrete parent edges. Replay checks that two argument slots bound to the same object never collapse into a pair bound to distinct objects.

Because the goal and all path constraints are invariant and transitions commute with the object permutations, an orbit step can be lifted from any representative to a corresponding concrete step at equal unit cost. BFS retains concrete parent edges, producing a shortest path with original names. For an invariant starting state, every member of a reachable orbit is reachable. The orbit sizes follow from factorials of block sizes divided by factorials of identical local signatures. The sum counts the full named-state space without expanding it. Multiplying each state-orbit size by the concrete action multiplicity at one representative counts named edges as well. These proofs apply to the checked fragment and observations.

## Reproduced results

| Published task | Reachable named states | Reachable state orbits | Shortest plan |
| --- | ---: | ---: | ---: |
| Gripper, 4 objects | 256 | 32 | 11 |
| Gripper, 6 objects | 1,856 | 48 | 17 |
| Gripper, 10 objects | 68,608 | 80 | 29 |
| Gripper, 20 objects | 243,269,632 | 160 | 59 |
| Gripper, 42 objects | **4,164,950,046,015,488** | **336** | **125** |
| Blocks, 4 objects | 125 | 125 | 6 |
| Miconic, 4 passengers | 2,048 | 2,048 | 14 |

The 42-object task visits 335 orbits before finding the shortest plan. There are 8,060 enabled actions over all state representatives, grouped into 1,336 action orbits. The independent Gripper audit counts configurations from the two grippers, two rooms and number of held objects, and verifies the shortest plan distance using capacity. Small tasks enumerate the concrete graph to check each state orbit and its successor classes. The comparison is against direct BFS and exact combinatorial audits. It supplies no measured wall-clock advantage over a tuned PDDL planner.

The four weight modules first compiled for four objects are frozen across all larger Gripper tasks. For the 42-object task, **340 grounded actions** reuse those four graphs and their **24 graph nodes**. The flat compiler uses 2,868 nodes. Including data bindings and metadata, the serialized artifact is **54,397 bytes**, compared with **101,853 bytes** for the flat compiler. Miconic reuses an existing graph for **56 of 64 actions**. Blocks needs new graph layouts. Across the seven tasks, **11,852** local input valuations agree with all reference paths.

The executor commits each named plan atomically, records ordered actions and recovers the same receipt across a journal to SQLite migration and restart. In the 42-object case, a new requirement gives one specific object a protected identity after seven steps have already committed. The old state quotient has an explicit collision: picking the protected object and picking its interchangeable peer originally belonged to the same class. The refined quotient keeps those states distinct. The same frozen model completes **116 remaining steps** while preserving the protected object at every step. A separate operator mutation removes pickup for that object but leaves the original goal intact. The planner then proves the original goal unreachable. Old epoch certificates cannot be used after a revision and migration.

Symmetry exploitation is established in automated planning. The contribution here is its integration with shared exact weight graphs, incident bindings for independently authored definitions, and revision-bound execution for changing observable scope. These experiments establish executable formal-definition transfer for the stated fragment. Arbitrary textual applications and a learned planning advantage over a specialized solver are open. ## Run

```sh
python3 experiments/model-applications/structural/replay.py --sources /tmp/holodeck-ipc --fetch
```

For offline replay, put the pinned source files in that directory and omit `--fetch`. The runner uses only the Python standard library.
