# Discover decision objectives from application effects

The experiment compiles synthetic application definitions into Holodeck checkpoints, enumerates completed two-step plans, and observes their ordered effects. Channel names come from execution. The decoder proposes one or two lexicographic objectives, with both signs, and derives sum, maximum, last event and count for repeated channels. The semantics of a missing effect in this experiment is zero. The objective grammar, plan horizon, calibration contexts and typed effect interface are part of the declared contract.

The response oracle compares two plans on an allowed calibration board. The target board is available as execution data. Its preference answers and best-plan labels are withheld from the solver. The results distinguish an objective within the grammar, a goal predicate that is enough to act, and a proof that the observations do not settle the decision.

## Exact decision and refusal

Given prior answers, the planner retains every consistent rule. Deployable decisions are in the intersection of their target optima. If that intersection is empty, the planner chooses a pair whose responses distinguish remaining rules. It groups rules by their entire response signature on the permitted question menu. Further queries cannot distinguish rules inside such a group. If every still possible response group has empty common optima, the system can prove that no future sequence of allowed questions will suffice and decline without exhausting the menu.

The minimax recurrence takes the minimum over distinct query partitions of one plus the worst descendant depth. A common optimum or a proof that no future query can lead to one gives depth zero. A separate bounded exhaustive search checks that a lower depth is impossible on each generated world. A separate checker verifies that a refusal certificate covers every still possible response signature and supplies valid mutually conflicting objectives. On the commit side, the session-supplied transcript and the actual ordered effects are checked before the existing epoch-bound atomic commit. The replay rejects a forged transcript, a forged plan, and an old certificate after a revision change and journal to SQLite migration.

Changing the current target can invalidate a prior consensus even when the same calibration remains valid. The replay includes a solved instance whose new target forces the two previously compatible candidate objectives to choose different plans. The committed optimum on the old target is insufficient state for future decisions.

## Measured results

Twelve deterministic generated worlds yielded **1,608 candidate rules** and **919 distinct response and target classes**. The exhaustive run verifies every class, selects the right choice when identifiable and proves a conflict otherwise. **837** classes admit a robust decision and **82** force a refusal. All twelve worst-case bounds for either decision or proof of refusal are verified and range from **three to five** questions.

| Strategy | Questions over 919 classes |
| --- | ---: |
| Identity-first minimax where identifiable, with a largest-branch heuristic fallback for indistinguishable classes | 4,397 |
| Largest-branch heuristic with decision-aware stopping | 3,870 |
| Minimax to a decision where globally possible, otherwise decision-aware heuristic | 3,597 |
| Minimax to either a decision or a verified impossibility result | **3,438** |

These are equally weighted simulation classes, not independent users or a prior over real requests. The worst-case-optimal policy need not ask fewer questions on each individual path.

Four fixtures and their reference rankings were generated by a separate model after the protocol was fixed. The solver and the first evaluation code were frozen before opening the answers. The subsequent minimax extension for proof of deferral is reported separately. Fixtures are synthetic, and the author knew the accepted grammar. All four graders fall inside the declared grammar. Their actual target preferences were excluded from elicitation.

| External fixture | Result | Questions in frozen run |
| --- | --- | ---: |
| Bridge spans | Correct plan, secondary criterion breaks a tie | 2 |
| Substation feeders | Correct plan, largest event value matters | 3 |
| Floodgate basin | Correct plan, final reading and count break the ranking | 4 |
| Sewer overflow | Certified underdetermination, total and peak select different plans | 2 |

The exact policy that minimizes the worst path to either outcome takes three questions on the last fixture. All three selected plans have their ordered effects checked against actual committed records. The external author gave conventional descriptions of the hidden rules and independent strict and tied preference groups. The benchmark covers unfamiliar effect names rather than unrestricted source applications.

## Continuous weights

A separate exact oracle supports up to four effect dimensions and arbitrary weights in a signed compact cube. A strict comparison is a strict linear inequality on the weights. Closing strict inequalities can create boundary points that match no plausible strict intent. Check for a strictly feasible point first. If each strict normal has a positive value at some vertex of the closed polytope, averaging those vertices gives a point satisfying all strict constraints. Otherwise there is no feasible strict intent. The closure is valid for evaluating universal weak optimality only once that witness exists.

If an optimum loses at a closure vertex, mix that vertex with the strict witness by a sufficiently small rational fraction. The result is a compatible intent under which the candidate truly loses. In the 3D test, three additional comparisons certify a shared optimum across infinitely many possible weights. The independent grid verifies 70 compatible weights; rational vertex and strict-witness checks give the universal statement for this bounded example. Opposite strict answers are rejected even though their weak closures contain a weight vector.
