# Illustrations and credits

The [current runtime diagram](illustrations/joint-deck-runtime.svg) and the [blind replay chart](illustrations/joint-deck-evidence.svg) accompany the [joint deck experiment](../docs/joint-deck.md). The [Hafenrechnung journey illustration](illustrations/joint-deck-journey.svg) follows the same synthetic order as the [Storefront](experiments/joint-deck/hafenrechnung-storefront.png), [Checkout](experiments/joint-deck/hafenrechnung-checkout.png) and [Admin](experiments/joint-deck/hafenrechnung-admin.png) captures. Chrome recorded all three in one percentage coupon run with Shopware stopped.

The illustrations and experiment captures accompany Stefan Hamann’s *The End of Software as We Know It: From Apps to Holos*. The editorial artwork depicts the vision. The experiment captures depict the existing Holoshop trial. They serve different purposes in the documentation.

The [service specialist illustration](illustrations/joint-deck-learning.svg) follows the activation of the published checkpoint. The [before](experiments/joint-deck/birkenkai-before-activation.png) and [after](experiments/joint-deck/birkenkai-after-activation.png) images show the same Birkenkai order in Chrome. [Learning experiment](../docs/learning.md#one-specialist-from-training-to-activation)

The [trace induction illustration](illustrations/trace-induction.svg) shows the different final-total expressions acquired from the regular and deliberately modified reference. [Trace induction evidence](../docs/trace-induction.md)

The [Nordufer capture](experiments/quantity-transfer/nordufer.png) shows the generated quantity control from the [quantity transfer experiment](../docs/quantity-transfer.md).

The [Muehlenbogen capture](experiments/hidden-quantity/muehlenbogen.png) shows a Holoshop using the [quantity policy recovered from masked Shopware traces](../docs/hidden-quantity.md).

The [shipping rule chart](illustrations/shipping-rule-acquisition.svg) uses the native replay's counts at equal observation budgets. [Experiment](../docs/shipping-rules.md)
